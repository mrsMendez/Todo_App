# TODO App - Sistema de Gestión de Tareas

##  Descripción de proycto
Aplicación web para gestionar tareas. Permite crear, visualizar, marcar como completadas y eliminar tareas. Desarrollada con Node.js, PostgreSQL, HTML/CSS/JS y Docker.

##  Arquitectura
- **Frontend**: HTML5, CSS3, JavaScript Vanilla, servido con Nginx
- **Backend**: Node.js + Express + PostgreSQL
- **Base de Datos**: PostgreSQL 15
- **Orquestación**: Docker Compose con tres servicios
